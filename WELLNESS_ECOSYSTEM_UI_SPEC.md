# Wellness Commerce Ecosystem UI Spec

## Style Direction

This system is designed to feel premium, calm, and modern across every surface.

- Visual mood: wellness luxury with soft mint and forest tones, warm sand highlights, glass panels, and smooth shadows.
- Layout philosophy: large typography, generous spacing, bold section rhythm, and clear hierarchy before decoration.
- Interaction language: rounded controls, subtle lift on hover, soft blur, minimal iconography, and lightweight motion.
- System behavior: the storefront feels editorial, the client dashboard feels supportive, the admin panel feels operational, and the mobile app feels thumb-first.

## Design System

### Color palette

- Primary gradient: mint to forest green for hero backgrounds, primary CTAs, premium emphasis.
- Core green: used for actions, highlights, and progress indicators.
- Warm sand: used as a balancing highlight in backgrounds and soft contrast areas.
- Neutrals: white, mist, sage-tinted gray, and dark slate-green for text hierarchy.
- Functional colors:
  - Success: green
  - Warning: amber
  - Info: cool teal
  - Destructive: restrained red

### Typography

- Headings: bold editorial sans with tight tracking and strong scale.
- Body: clean geometric sans for readability in dense dashboards and tables.
- Hierarchy:
  - Hero: oversized display headlines
  - Section titles: strong H2/H3 rhythm
  - Utility labels: small uppercase with wide tracking
  - Data text: high-contrast, concise, and scannable

### Core components

- Buttons:
  - Primary: gradient green pill with shadow
  - Secondary: white or translucent pill with border
  - Icon button: compact circular action for search, notifications, settings
- Cards:
  - Surface card: rounded, lightly elevated, white glass
  - Strong surface: bigger radius, higher shadow, subtle gradient fill
  - Metric card: concise KPI presentation with icon chip
- Navigation:
  - Public nav: floating pill navigation with minimal actions
  - Dashboard sidebar: rounded nav states with clear active emphasis
  - Admin nav: neutral operational shell with stronger active contrast
- Tables:
  - Clean banded header
  - Spacious row height
  - Soft hover states
  - Minimal visual clutter
- Icon style:
  - Outline-first
  - Small, clean, and informational rather than decorative

## Page-by-Page UI Descriptions

### 1. Landing Page

- Goal: introduce the brand with a premium, wellness-driven first impression and preview the full digital ecosystem.
- Layout structure:
  - Floating glass navbar
  - Large hero with green gradient atmosphere
  - Product mockup stage with overlay insight cards
  - Benefits grid
  - Product highlights section
  - Screen-family showcase
  - Design system section
  - Testimonials and stats
  - CTA block
  - Newsletter and simplified footer
- Key components:
  - Hero CTA pair
  - Floating trust and mobile cards
  - Benefit tiles
  - Product card grid
  - Ecosystem feature cards
  - Color and typography showcase

### 2. Client Dashboard

- Goal: give customers a premium account workspace that feels useful, calm, and easy to scan.
- Layout structure:
  - Rounded top utility bar with search and notification controls
  - Left sidebar with profile summary and primary navigation
  - Welcome hero panel with recommended next action
  - KPI row for orders, reviews, cart value, and spend
  - Purchase cadence chart area
  - Account health modules
  - Recent orders table
  - Review activity and quick tools rail
- Key components:
  - Sidebar navigation
  - Priority action card
  - Minimal progress bars
  - Data table for orders
  - Review activity cards

### 3. Admin Panel

- Goal: keep the admin professional and operational while preserving the same premium system.
- Layout structure:
  - Persistent left admin sidebar
  - Top utility bar with search, notifications, and settings
  - Page-level pills for fast section switching
  - Elevated content shell for dashboards, charts, and tables
  - Analytics hero and priority board
  - Reusable KPI and chart cards
- Key components:
  - Functional navigation groups
  - Operational hero section
  - Stat cards
  - Analytics cards
  - Clean data tables
  - Product, order, user, and review management surfaces

### 4. Mobile App Version

- Goal: compress the same premium brand language into a thumb-friendly interface.
- Screen set:
  - Home: featured cards, quick categories, premium highlights
  - Product detail: strong image, compact trust cues, sticky purchase action
  - Cart and checkout: large summary blocks, readable totals, low-friction actions
  - Profile/dashboard: compact KPIs, order status, and quick settings
- Mobile principles:
  - Large tap targets
  - Rounded cards
  - Strong vertical rhythm
  - Minimal top-level actions
  - One-hand reach priority

## System Notes

- White space is a feature, not filler.
- Green is the primary emotional tone, not an accent used everywhere at equal strength.
- Shadows stay soft and broad rather than dark and sharp.
- Rounded corners are consistent across all surfaces so the system feels related.
- Data-heavy surfaces reduce decorative color and rely more on spacing and typography.
